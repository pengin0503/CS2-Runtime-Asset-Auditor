# パネルの見た目をゲーム内 UI に合わせた変更の検証状況 — 2026-10-11

ゲームの UI バンドル（1.6.2f1 の `index.css` / `index.js` / `Media`）を参照して、パネルの見た目と部品をゲーム内のものに寄せた。実施した検証と未実施の項目を記録する。自動テストとブラウザーでのプレビューの成功を実機での PASS とは扱わない。

## 変更

- 配色・角丸・文字サイズを、ゲームが `:root` とインターフェーススタイル（`.style--bright-blue` / `.style--dark-grey-orange`）で定義する CSS 変数から取る（`--panelColorDark`、`--sectionBackgroundColor`、`--accentColorNormal`、`--fontSizeS` など）。固定色は使わない。
- 構成は経済パネル（`iceflake-panel` テーマ）に合わせた。暗いタイトルバーに大文字・太字のタイトル、上辺が丸いタブ（選択中はハイライトのグラデーション）、グラデーションの本文、セクション背景のカードと行。
- 閉じるボタンはゲームのグリフ `Media/Glyphs/Close.svg` を色付きの丸ボタン（`Button variant="round" tinted`）で表示する。展開の矢印は文字の「▸ ▾」から `ThickStrokeArrowRight/Down.svg`（cs2/ui の `Icon`）に変えた。
- `title` 属性の説明を cs2/ui の `Tooltip` に置き換えた（列の説明、計測の根拠のバッジ、概要カード、ドラッグ・サイズ変更の案内）。Gameface がネイティブのツールチップを描画するかは確認していないが、ゲーム自身は `title` ではなく `Tooltip` を使っている。
- アセット画面の素の `<button>` を cs2/ui の `Button`（flat / primary / text）に置き換えた。ゲームのボタンの見た目・効果音・フォーカス処理が付く。
- ランチャーアイコンは変更していない（色付きマスク表示にすると `coui://ui-mods/` の画像をマスクに使うことになり、表示されなくなる恐れがあるため）。

`Tooltip` は子要素の DOM に参照を付けて表示するため、子は HTML 要素か cs2/ui の部品に限る（自前の関数コンポーネントを直接包むと表示されない）。
